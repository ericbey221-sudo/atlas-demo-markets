ATLAS DEMO MARKETS — FREE DEMO WEBSITE

This is a static paper-trading/demo interface. It does NOT process money,
real trades, deposits, withdrawals, or real brokerage accounts.

FILES
- index.html: pages and dashboard markup
- style.css: responsive black/gold styling
- app.js: sample market data, demo transactions, chart, and local demo profile

FREE HOSTING
1. Create a GitHub account.
2. Create a new PUBLIC repository, e.g. atlas-demo-markets.
3. Upload index.html, style.css, and app.js.
4. Open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and / (root), then Save.
7. GitHub will provide the public Pages address.

IMPORTANT
Keep the DEMO / PAPER TRADING notice visible. Replace sample company details
with your real business information if you use this for an educational demo.
Do not present fictional balances or transactions as real client funds.
